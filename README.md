# Бот-копилка шуток про Васю 🥲

Телеграм-бот для группы: собирает шутки про Васю и выдаёт по запросу.
Живёт на Supabase (бесплатно), без своего сервера. Настраивается полностью в браузере.

- Бот: **@<ваш_бот>**
- Supabase Project ID: **<PROJECT_REF>**

## Что он умеет

| Команда         | Что делает                                         |
|-----------------|----------------------------------------------------|
| `/add <текст>`  | добавить шутку (дубли отсекаются)                  |
| `/joke [номер]` | случайная, либо конкретная по номеру из `/list` (напр. `/joke 3`) |
| `/top`          | топ самых залайканных                              |
| `/list`         | показать все, листается кнопками ◀️ ▶️             |
| `/count`        | сколько всего накопилось                           |
| `/find <слово>` | поиск по шуткам (с номерами как в `/list`)         |
| `/stats`        | статистика: топ авторов, лайки, счётчик «место»    |
| `/export`       | выгрузить все шутки файлом (бэкап)                 |
| `/del <номера>` | удалить, напр. `/del 1 3 5` (только удаляющие)     |
| `/edit <N> <текст>`| изменить шутку по номеру (только удаляющие)     |
| `/lenya on\|off`| разрешить/запретить Васе добавлять (только админы)        |
| `/mesto on\|off`| вкл/выкл реакцию «на место» (только админы)               |
| `/ugabuga on\|off`| вкл/выкл реакцию на «уга-буга» и «уга» (только админы)  |
| `/pivo on\|off` | вкл/выкл реакцию «Кто сказал пиво?!!» (только админы)     |
| `/tut on\|off`  | вкл/выкл «аукание» Васи раз в день (только админы)        |
| `/links on\|off`| вкл/выкл реакцию на ссылки от @<link_spammer> (только админы) |
| `/ogryz on\|off`| вкл/выкл огрызания на ответы и реакции на сообщения бота; `/ogryz test <фраза или эмодзи>` — проверить (только админы) |
| `/ai on\|off`   | вкл/выкл ИИ-режим: обращение «бот, …», @тег (только админы) |
| `/shield on\|off` | защита создателя от оскорблений и прожарки, по умолчанию выкл (только админы) |
| `/roast [@ник\|имя]` | прожарка участника по его шуткам из копилки (или ответом на его сообщение) |
| `/sud` | рассудить спор по последним 40 сообщениям (или «Малыч, рассуди»; лучше ответом на спорное сообщение) |
| `/predict on\|off` | утренние предсказания каждому активному участнику с тегом (только админы) |
| `/here`         | слать «шутку дня» в этот чат — вкл/выкл (только админы)   |
| `/admin`        | админка: список «на место» — кого посылать (только админы) |
| `/place add\|del @ник`| быстро править список «на место» (только админы)    |
| `/phrases`      | варианты фраз «на место» — добавить/убрать (только админы) |
| `/owners`       | назначать/снимать админов (только админы)                |
| `/start`        | показать список команд                             |

> 💡 **Нумерация шуток теперь сверху-вниз от новых к старым:** №1 — самая свежая.
> Это касается `/list`, инлайна и номеров в `/joke N`, `/del N`, `/edit N`.

**Inline-режим** (слать шутки в любой чат): набери `@<ваш_бот> <слово>` в поле
ввода любого чата — появятся подходящие шутки, выбираешь и отправляешь. Без слова —
показывает последние. Требует включения у @BotFather: `/setinline` → выбрать бота →
задать подсказку (напр. `найти шутку про Васю`).

**Реакции на обычные сообщения:**
- **«на место»** — на любое сообщение того, кто есть в списке «на место», бот отвечает фразой
  вроде `Вася, место! 🐕`. Список редактируется через `/admin` (или `/place add|del @ник`) —
  кого хочешь, того и посылаешь; изначально там Вася, но его можно убрать.
- **«уга-буга»** — кто напишет «уга-буга» (в любом виде), того бот похвалит голосом туземца
  («моя гордиться твоя!» и т.п.).
- **«уга»** — на одинокое слово «уга» бот моментально отвечает `буга` (без эмодзи).
- **«пиво»** — на любое сообщение со словом «пиво» бот пишет в чат `Кто сказал пиво?!!`.
- **«Вася, ты тут?»** — раз в день в случайный час (12:00–23:00 МСК) бот тегает Васю
  (`@<lenya>`) с вопросом «ты тут?». Как только Вася впервые что-нибудь напишет —
  бот объявляет в чат `Пацаны, он тут!` и до следующего дня молчит. Рубильник `/tut`.
- **ссылки от @<link_spammer>** — если он кидает в чат любую ссылку, бот отвечает ему цитатой
  `Почему ему все еще не запретили отправлять ссылки сюда??`. Ссылка ловится и по разметке
  Telegram, и по тексту (`https://…`, `www.…`, `t.me/…`, `что-нибудь.ru/com/…`). Рубильник `/links`.
- Все флаги по умолчанию включены, рулятся командами `/mesto`, `/ugabuga`, `/pivo`, `/tut`, `/links`, `/ogryz`.
- Огрызания: когда кто-то отвечает (reply) на сообщение бота, бот огрызается. Если в секретах задан `GEMINI_API_KEY` — ответ придумывает Gemini по контексту (модели перебираются по цепочке, см. `GEMINI_MODELS`, первую можно задать секретом `GEMINI_MODEL`); если ключа нет или Gemini лёг — берётся фраза из встроенных списков `SNAP_*`. Реакции (лайки и т.п.) на сообщения бота тоже вызывают огрызание: бот запоминает свои сообщения в таблице `bot_messages` (миграция 0016). Чтобы Telegram присылал реакции, бот должен быть **админом** группы, а вебхук — привязан с `allowed_updates`, включающим `message_reaction` (делается запросом на функцию `?task=webhook` с заголовком `x-cron-secret`).
- ИИ-режим (Gemini): обращение к боту («бот, …» в начале сообщения, @тег, или голосовое) разбирается в JSON `{intent, arg, reply}` — бот отвечает словами и/или выполняет команду (add/joke/top/find/count/stats/list/roast/help); intent `compose` («Малыч, запиши шутку про …» без готового текста) — бот сам сочиняет шутку по последним 50 сообщениям чата и примерам из копилки, записывает её (автор «Пихал Малыч») сразу с контекстом и кнопкой «📖 Контекст». Огрызания на реакции — не чаще раза в 90 с на одно сообщение (ключи `rsnap:*` в `counters`). Антиспам (миграция 0018, таблица `spam_guard`): больше 6 дёрганий бота (обращения, ответы боту, реакции на его сообщения) за 2 минуты — бот один раз грубо посылает с просьбой не спамить, и 15 минут от этого человека не обрабатывается вообще ничего: текст, команды, стикеры, голосовые, медиа, реакции, кнопки (глобальный `bot.use` перед всеми обработчиками; главный админ под мьют не попадает). Свои сообщения бот помечает видом (`bot_messages.kind`, миграция 0020): `service` — шутки, списки, контекст, «Записал», справка (на лайки и ответы к ним бот молчит, кроме просьб словами), `talk` — реплики (пиво, место, ответы ассистента, прожарка), `snap` — огрызы (на лайки к ним отвечает с вероятностью 15%); помечается через `sendTalk`. Если к боту обратились на «вы» (`isFormal`: вы/вас/ваш…, здравствуйте, пожалуйста, глаголы на -йте/-ите), он отвечает как карикатурный интеллигент в пенсне и тоже на «вы» (SNAP_SYSTEM_POLITE / POLITE_ADDENDUM / SNAP_POLITE). Защита создателя (`/shield on|off`, флаг `baha_shield`, по умолчанию **выкл**): при включении просьбы оскорбить или прожарить создателя (`isProtected`: ник владельца, имя, фамилия из config.ts; intent `refuse` через REFUSE_RULE) бот отклоняет — грубо на «ты», вежливо на «вы» (REFUSE_RUDE / REFUSE_POLITE) через `runCommand`, который прогоняет фальшивый апдейт `/cmd arg` через те же обработчики. На голосовые, стикеры, фото, видео и любые сообщения без текста бот не реагирует вообще (ранняя проверка в обработчике сообщений). Шутка дня получает злобный комментарий от Gemini. Счётчики: `ai_asks`, `roasts`. Бота зовут **Пихал Малыч** — откликается на «Пихал», «Малыч», «бот».
- Контекст шуток (миграция 0017): бот пишет все сообщения чата в `chat_log` (чистится через 3 дня). При `/add` (и при «Пихал, добавь шутку …») он в фоне берёт 40 сообщений перед шуткой (люди + свои из `bot_messages`) и просит Gemini пересказать, к чему шутка; если связи нет — ничего не сохраняет. Сообщения после шутки не смотрит (второй проход через `context_jobs` был и убран, таблица в базе осталась пустой). Под `/list` — кнопки-номера (callback `open:<id>`), которые шлют шутку в этот же чат; `/start j<id>` тоже присылает шутку (диплинк). Если есть — пишет в `jokes.context`, меняет ответ на «Контекст тоже запомнил» и вешает кнопку «📖 Контекст» (она же появляется у такой шутки в `/joke` и в шутке дня). У старых шуток контекста нет.

**Админка (в личке с ботом):** админ пишет боту `/admin` в личные сообщения — бот показывает
список «на место» с кнопками ❌ для удаления и подсказкой, как добавить (`/place add @ник`).
Сами фразы посылания редактируются через `/phrases` (`/phrases add текст`, `/phrases del номер`,
или кнопками ❌). В тексте фразы можно вставить `{name}` — подставится имя того, кого послали.

> ⚠️ **Чтобы реакции работали, у бота должен быть ВЫКЛЮЧЕН privacy mode:**
> @BotFather → `/mybots` → @<ваш_бот> → Bot Settings → Group Privacy → **Turn off**,
> затем **удалить бота из группы и добавить заново** (иначе не подхватится).
> С включённым privacy бот видит только команды и реакции работать не будут.

**Автопосты по расписанию** (в чаты, привязанные через `/here`):
- 🗓 **Шутка дня** — ежедневно 09:00 UTC (≈12:00 МСК).
- 🏆 **Шутник недели** — по воскресеньям 18:00 UTC (≈21:00 МСК): топ-автор недели + лучшая шутка недели.
- 👀 **«Вася, ты тут?»** — раз в день в случайный час окна 09:00–20:00 UTC (12:00–23:00 МСК).

Расписание стоит в pg_cron (задания `daily-joke`, `weekly-digest`, `lenya-ping`), они дёргают
функцию `?task=daily` / `?task=weekly` / `?task=ping` с секретным заголовком. Пинг тикает
каждый час окна, а сам бот выбирает случайный час (ровно один пинг в день). Поменять время —
обновить cron-задание. Чтобы посты приходили — владелец один раз пишет `/here` в нужном чате.

**Права:**
- **Админы** рулят всеми настройками и могут удалять/редактировать шутки. Главный админ —
  **@<owner>** (зашит в коде, снять нельзя). Остальных админ назначает командой `/owners`
  (или `/owners add @ник`), снимает кнопкой ❌ или `/owners del @ник`.
- Отдельно удалять/редактировать могут ещё **@<friend1>**, **@<friend2>**, **@<friend3>**
  (заданы в коде, `DELETERS`) — это «модераторы» без доступа к настройкам.
- Добавлять шутки могут все, **кроме @<lenya> (Васи)** — ему можно только когда админ
  включил `/lenya on`. По умолчанию выключено.
- Привязка к никам. Сменишь ник в Телеграме — права слетят (тогда лучше перейти на числовые id).

**Нумерация:** в `/list` номера сквозные (1, 2, 3… без дыр) и пересчитываются после
удаления. `/del` принимает эти номера, в т.ч. списком: `/del 2 5 9`.

Лайки/дизлайки считаются по людям (один человек = один голос, повторное нажатие снимает голос).

## Как запустить — всё в браузере, кодить не надо

### Шаг A. Создать таблицу
Supabase → **SQL Editor** → New query → вставить содержимое
`supabase/migrations/0001_init.sql` → **Run**.

### Шаг B. Создать бота
Supabase → **Edge Functions** → **Deploy a new function** → **Via Editor** →
имя функции `bot` → вставить содержимое `supabase/functions/bot/index.ts` → **Deploy**.

### Шаг C. Секреты
Edge Functions → **Secrets**. Добавить:

| Key | Value |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | `<WEBHOOK_SECRET>` (любой пароль без пробелов) |

`SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` подставляются автоматически.

### Шаг D. Отключить JWT
Открыть функцию `bot` → настройки → выключить **Verify JWT / Enforce JWT verification**.
Иначе Telegram не сможет достучаться (бот будет молчать). Защита остаётся за счёт секрета из Шага C.

### Шаг E. Привязать вебхук
Открыть в браузере (подставив свой токен, Project ID и тот же секрет):

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://<PROJECT_ID>.supabase.co/functions/v1/bot&secret_token=<WEBHOOK_SECRET>
```

Ответ `"ok":true` = подключено.

### Шаг F. Группа
В @BotFather: `/setjoingroups` → Enable. Добавить бота в группу.
Проверить: `/add Вася опять проспал`, затем `/joke`.

## Если что-то не так

- **Бот молчит** — чаще всего не отключён JWT (Шаг D) или не совпал `secret_token` (Шаг E vs Шаг C).
- **Логи/ошибки** — Supabase → Edge Functions → функция `bot` → вкладка Logs.
- **Поменял код** — открой функцию `bot` в редакторе, поправь, нажми **Deploy updates**. Вебхук заново настраивать не нужно.
- **Посмотреть/почистить шутки** — Supabase → Table Editor → таблица `jokes`.

## Где что лежит

```
supabase/
├── functions/bot/index.ts   ← мозги бота (логика команд)
├── migrations/0001_init.sql ← описание таблицы со шутками
└── config.toml              ← настройки (нужны только для способа через терминал)
```

> Примечание: способ через терминал (Supabase CLI) тоже рабочий, но для некодера
> браузерный путь выше — проще. CLI пригодится, если захочешь версионировать функции.


- Ночной режим (01:00–08:00 по Ашхабаду, UTC+5): бот сонный и злой, отвечает до 60 символов; огрызы, болтовня и огрызы на реакции — с вероятностью 50%. Команды работают как обычно.
- Предсказания дня: после шутки дня (cron daily) для каждого, кто писал в чат за 3 дня (до 15 человек, по `chat_log.user_id/username`, миграция 0021), Gemini пишет предсказание; тег — @ник или ссылка на профиль.

## Личный ассистент (только личка создателя)

Миграции 0022 (таблицы `pa_*`, pgvector, RLS без политик) и 0023 (cron `pa-remind` каждую минуту, `pa-summary` в 03:00 UTC = 08:00 Ашхабад). Секрет `PA_SECRET_KEY` — ключ AES-GCM для доступов.

- Владелец: ник `SUPER_OWNER` в личке; его id запоминается в `counters.pa_owner_id` (туда же шлются напоминания и сводка).
- Любое сообщение (текст, голосовое, скриншот, пересланное, геолокация) → память (`paMemory`: напоминания, люди, похожие заметки по смыслу, названия доступов, история) → Gemini (`PA_SYSTEM`, JSON: reply, alert, actions) → действия (`paApply`): note / remind / person / forget_* / cancel_reminder / secret_start.
- Доступы: «сохрани пароль/доступ/ключ …» (или `/pass new`) распознаётся без нейросети → следующее сообщение шифруется, удаляется из чата, в Gemini не уходит. «дай пароль от …» / `/pass` — выдача без нейросети, сообщение с паролем удаляется через минуту.
- Геолокация: точка хранится час, заметки привязываются к месту; при новой точке (в т.ч. живой трансляции) рядом с заметками (400 м) — напоминание о важном, не чаще раза в 6 часов на место.
- Команды: `/pa` справка, `/pass`, `/mem` выгрузка файлом (без значений паролей), `/forget`, `/pasum on|off`.
- Личка не пишется в `chat_log` и `bot_messages`.

## Устройство кода (с версии 75)

`supabase/functions/bot/`:
- `index.ts` — точка входа, вызывает регистрацию обработчиков строго по порядку.
- `core.ts` — общее: подключения, константы, утилиты, Gemini, журналы, мьют, огрызания и ИИ-режим группы.
- `assistant.ts` — личный ассистент (зависит только от core).
- `group.ts` — команды копилки, обработчик сообщений, реакции, cron-задачи, `Deno.serve` (зависит от core и assistant).

Каждый файл экспортирует свои объявления и функцию `register…()`; порядок `core → assistant → group` важен (журнал ответов и мьют → перехват секретов/сканов → команды → сообщения). Деплой — все `.ts` из папки одним запросом `functions/deploy` (multipart, несколько `file`).
